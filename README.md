# FoundIt 

**FoundIt** is a campus lost-and-found web application designed to help students, faculty, and staff quickly report, locate, and recover missing items around campus. 

Built as part of ITSC 3155 (Software Engineering), FoundIt bridges the gap between individuals who lose items and official campus drop-off locations (such as library front desks, student centers, and campus safety offices) through an intuitive, real-time platform.

---

### Key Features
* **Item Feed & Search:** Browse active lost and found items categorized by type, location, and date.
* **Item Post Creation:** Easily submit a report for a lost or found item with details, photos, and last-seen locations.
* **Campus Drop-off Points:** Locate verified campus drop-off hubs where found items can be safely submitted and reclaimed.
* **Category Filtering:** Quickly narrow down searches by item type (e.g., Electronics, Keys, IDs, Apparel).
